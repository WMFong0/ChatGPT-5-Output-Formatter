
# ChatGPT-5 Output Formatter

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/WMFong0/ChatGPT-5-Output-Formatter/blob/Google-Colab-Version/ChatGPT_5_Formatter.ipynb)

A simple Python tool to clean and format text output from ChatGPT, removing extra spaces and fixing capitalization errors. Designed for use in Google Colab with Python 3.7.

## Features
- Removes extra spaces from text
- Fixes capitalization errors (each word capitalized)
- Easy to use: paste your text and get formatted output

## Requirements
- Google Colab
- Python 3.7

## Usage
1. Open the notebook in [Google Colab](https://colab.research.google.com/github/WMFong0/ChatGPT-5-Output-Formatter/blob/Google-Colab-Version/ChatGPT_5_Formatter.ipynb).
2. Run the code cell and follow the prompt to input your ChatGPT output.
3. The tool will display the cleaned and formatted text.

### Example
Input:
```
AB C      C D     D  E
```
Output:
```
Ab C C D D E
```
