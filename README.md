
# ChatGPT-5 Output Formatter

ChatGPT-5 Output Formatter is a simple Python tool designed to clean and format text output from ChatGPT or similar models. It removes extra spaces and fixes capitalization errors. At least, your teacher won't know you're using it now.

## Features
- Removes extra spaces from text
- Fixes capitalization errors (each word starts with a capital letter)
- Easy to use in terminal

## Usage
1. Download it
2. Run the script:
	```bash
	python ChatGPT_5_Formatter.py
	```
3. Paste the output from ChatGPT when prompted.
4. The cleaned and formatted text will be displayed.

## Example
Input:
```
	this   is   a   SAMPLE   output   from   chatgpt.  
```
Output:
```
This Is A Sample Output From Chatgpt.
```
